# Веб-приложение "Ферма"

## Описание проекта

«Ферма» — веб-приложение для автоматизации учёта сельскохозяйственной продукции, управления урожаем, логистикой доставки и анализа деятельности фермерского хозяйства.

Система позволяет вести учёт продукции, контролировать сбор урожая, управлять транспортом, строить маршруты доставки с использованием генетического алгоритма и получать статистическую информацию по работе фермы.

# Логистическая оптимизация

Для построения маршрутов доставки используется генетический алгоритм.

Алгоритм выполняет:

- генерацию начальной популяции решений;
- оценку функции приспособленности;
- турнирный отбор;
- скрещивание хромосом;
- мутацию маршрутов;
- проверку ограничений;
- выбор наилучшего решения.

Для расчёта расстояний используется локальный сервер GraphHopper на основе данных OpenStreetMap.

Для ускорения работы предварительно рассчитывается матрица расстояний между всеми объектами маршрутизации, которая сохраняется в Redis и затем загружается в оперативную память приложения.
